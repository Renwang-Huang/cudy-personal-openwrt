## 回退材料与边界

设备上的私有备份目录为 `/root/ui-backups/argon-v3.1.2/`，包含原 LuCI 配置、
回退脚本和 `system-config-before.tar.gz` 完整配置备份。电脑另存一份安装前配置。
这些文件包含私人配置，未提交到 Git 或作为 Release 附件发布。

如需恢复原界面，通过 SSH 执行：

```sh
sh /root/ui-backups/argon-v3.1.2/rollback.sh
```

回退仅恢复原 LuCI 配置，保留主题与依赖包。
本次核对了实机备份、回退脚本内容和语法，未在正常工作的设备上执行回退。
安装与故障回退流程在此前电脑隔离副本中完成演练，见 [准备阶段记录](VALIDATION.md)。

此记录只覆盖一台设备及本次短时检查。未执行设备重启、长时间负载或新增插件组合测试。
