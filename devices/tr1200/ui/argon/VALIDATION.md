浏览器检查使用 Chromium，包括深浅色选择、跟随系统、手机菜单展开与收起、
登录预览跳转、资源加载和横向溢出检查。5 个场景均无 JavaScript 错误、缺失资源或外部请求。
预览页的导航和数据是固定示例；没有连接实机 RPC，也没有保存任何路由器登录会话。

安装脚本的隔离演练使用电脑上的根文件系统副本、实际目标架构 APK/UCI 工具，
设备标识、剩余空间和服务重启接口由本地测试桩提供。它验证离线事务、备份、
拒绝条件和配置恢复路径，不能替代真实闪存写入及 `rpcd` 重启后的行为检查。

实机只进行了只读访问，末次核对仍使用 Bootstrap、中文 LuCI；已安装包数据库与检查开始时一致，
overlay 约 8.8 MiB 可用。尚未实测 Argon 登录、RPC 权限、保存设置、前端插件兼容性和长期内存开销。
现有固件镜像、设备构建配方和旧版本固定输入均未更改。
