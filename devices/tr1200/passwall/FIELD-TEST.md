# PassWall · 单台 TR1200 实机记录

日期：2026-11-03。仅覆盖一台 Cudy TR1200 v1，OpenWrt 25.12.5，Linux 6.12.94。

## 部署结果

- PassWall 26.10.29-r1、中文包已安装，LuCI 菜单位于“服务 → PassWall”。
- 核心为 sing-box 1.13.21-cudy-lite.3，自编译 MIPS 小端软浮点版本。
- dnsmasq 2.93-r99 保留 DHCP、普通 DNS 和 nftset；不包含 DNSSEC 及其大体积依赖。
- 完成保留配置升级，原 SSH 密钥、管理员密码、网络、无线、Argon 和中文设置保留。
- PassWall 初始化为 DHCP 增加 `localuse=1`，为防火墙增加集成 include；既有防火墙规则已按 UCI 语义核对一致。
- 插件默认提高管理服务并发数，现场已恢复原有管理服务配置。
- 包装脚本使用单线程、24 MiB Go 内存软目标与积极回收；精简核心约 4.83 MiB。
- 现场可写空间约 2 MiB，代理和 SOCKS 服务均关闭，未配置真实节点或订阅。

## 首次启动观察

首次升级期间写入和启动时间长于初始预估，电脑观察到多次链路重建。
随后设备恢复到原管理地址，SSH 和核心服务通过核对，未发现内核崩溃或内存耗尽记录。
不能仅凭短时链路中断认定启动循环；此次没有进行 Reset 或恢复出厂设置。

构建过程发现本机默认文件掩码会产生带组写位的目录，现场已规范根目录、`/etc`、
`/etc/uci-defaults`、`/tmp` 权限。后续构建必须使用 `umask 022` 并检查镜像目录权限。

## 备份、回退与未覆盖范围

安装前后配置、初始完整闪存和原 v0.1.1 镜像均保存在本机私有目录。
原 Argon 回退配置和脚本也已保留。私人配置、密码、SSH 私钥、截图和测试凭据未上传。

只关闭 PassWall 时，可在管理页关闭总开关，或通过 SSH 执行：

```sh
/etc/init.d/passwall stop
/etc/init.d/passwall disable
```

恢复到原 v0.1.1 需要使用匹配型号的旧镜像和安装前配置进行升级回退，
不建议通过逐个卸载 DNS、Lua 或网络依赖包恢复基础系统。

尚未验证真实订阅、真实节点、公网出口、代理吞吐、长时运行或多连接负载。
这次部署未补充原固件的 WAN 和无线性能测试。当前仍作为单台设备的候选配置使用。
